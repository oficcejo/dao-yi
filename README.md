一个把 **八字旺衰、六经辨证、贝叶斯证据汇总** 组合起来的 Android **典籍学习推演工具**。纯端侧运行、用户自带大模型 API Key，所有输出经规则闸门校验后以结构化卡片呈现。

> ### 使用前必读（重要声明）
>
> 本项目是**个人自用与典籍研究**性质的技术实验，**不是**医疗器械、诊断工具或处方系统。
>
> - 依据《互联网诊疗监管细则（试行）》第二十一条：**处方应由接诊医师本人开具，严禁使用人工智能等自动生成处方**。因此本项目所有输出仅定位为「典籍条文整理与方证学习推演」，不构成任何医嘱。
> - 知识库与剂量表**未经中医师审校**，取自公开典籍与《中国药典》常用量；汉代剂量折算在学界存在争议，程序内以双轨方式标注。
> - 八字体质判定**缺乏现代循证依据**，仅作为传统文化参考维度，默认只以低权重调制先验（λ = 0.15，可置 0 完全关闭）。

> - 项目不收集、不上传任何生辰与健康数据；请勿将其用于对外提供诊疗服务，也不要据此上架应用商店。

## 它做什么

输入公历生辰（日期 + 十二时辰 + 出生地经度）与症候描述，程序在端侧完成排盘、症候编码与贝叶斯推理，再由大模型把已算好的证型后验组织成结构化文案，最终经安全闸门校验后展示：四柱盘、五行力量、大运流年、五运六气、证型后验与证据贡献、方剂 / 中成药 / 养生学习卡。

**核心边界：生辰不上云，LLM 不做概率判断。** 请求体只携带证候编码、偏性向量与证据链，不携带原始生辰；概率计算全部在端侧确定性完成。

## 五层数据流

| 层 | 职责 | 关键实现 |
|---|---|---|
| 输入 | 生辰、症候、体质标签 | 可视化公历日期 / 十二时辰选择、周岁自动推算、红旗症状在推理前直接拒答 |
| 排盘 | 四柱与时空偏性 | 真太阳时、24 节气、藏干十神纳音、日主旺衰、大运流年、五运六气 |
| 辨证与推理 | 症候编码 → 方证后验 | 证据分组的对数域加权贝叶斯，输出逐条证据贡献 |
| 生成 | 组织结构化文案 | OpenAI 兼容接口（DeepSeek 等），严格 JSON 契约 + 中英文字段别名容错 |
| 闸门与展示 | 硬规则校验 → 结果卡 | 药典剂量、十八反十九畏、特殊人群、毒性药提示；合规免责区固定置顶 |

## 算法与工程要点

- **历法零依赖**：用太阳视黄经牛顿迭代求 24 节气（不查表、带缓存，精度约 1 分钟），真太阳时按经度 4 min/度 + 均时差校正；年柱以立春分界、月柱以节气分界、JDN 定日柱、五鼠遁定时；藏干本 / 中 / 余气、十神、纳音、十二长生；旺衰按得令 / 通根 / 透干 / 生扶 / 克泄耗 / 合冲逐项加减分；大运起运岁数（三日一岁）、顺逆排运；五运六气含中运、司天、在泉与主客气。
- **贝叶斯按证据组加权**：`log P(H|E) = log P₀(H) + Σ_g w_g · mean[log(P(E|H)/0.5)]`，组内取加权均值并做 `1/√n` 折扣，避免「恶寒 + 无汗 + 脉浮紧」被重复计数推到虚假的高置信；中性证据以 0 留在分母。八字偏性与五运六气**只调制先验**（λ = 0.15、μ = 0.10），λ 可置 0 做「纯中医辨证 vs 含八字」对照。
- **LLM 受约束**：知识库是「参考 + 校验」而非开方白名单，模型可自选经方；响应解析支持中英文字段名、Markdown 代码块包裹的输出、字符串药数组（如「桂枝 9g」）与嵌套对象；无 Key、HTTP 错误或非 JSON 响应会明确降级为**本地典籍参考卡**，不会白屏或吐乱码。
- **安全闸门**：红旗症状（胸痛、呼吸困难、高热不退、意识改变、剧烈腹痛、出血、妊娠、婴幼儿等）在输入层拒答；药典上限自动 clamp 并标注、十八反十九畏拦截、妊娠 / 儿童 / 老人禁忌、毒性药先煎提示、未收录药材提示。
- **剂量双轨**：「典籍折算量」（一两 15.625 g，按服法分次）仅作学习展示并标注存疑；程序实际输出的克数取《中国药典》现代参考量。「补不足损有余」落在饮食 / 作息 / 导引 / 情志 / 节气等养生层，不落在加重毒性药上。

## 隐私与数据

| 项目 | 做法 |
|---|---|
| 后端 | **无 BFF、无账号、无埋点**，`HttpURLConnection` 直连用户配置的接口 |
| 生辰数据 | 只在端侧参与排盘，不写入请求体、不持久化明文记录 |
| API Key | Android Keystore AES-256-GCM 加密后存应用私有区；密钥库损坏时降级存储并长期显示安全提示 |
| 离线 | 无网 / 无 Key / 模型失败均可降级为本地典籍参考卡 |
| 历史 | 仅本机、可一键清空 |

## 下载

前往 [Releases](https://github.com/oficcejo/dao-yi/releases) 下载：

| 资产 | minSdk | 签名 | 说明 |
|---|---|---|---|
| `DaoYi-Android6plus.apk` | 23（Android 6.0） | v1 + v2 | **推荐**，6.0 ~ 16 全系列可装；`java.time` 已做核心库脱糖，并补齐 TLSv1.2 兼容 |
| `DaoYi-Android8plus.apk` | 26（Android 8.0） | 仅 v2 | 改配置前的留档版本 |

> Android 6.0 只识别 v1 JAR 签名（v2 需 API 24+），所以兼容包必须双签名。两个包 `applicationId` 相同，**同一设备会互相覆盖、无法共存**；日常直接用 Android 6+ 版即可。

安装后：打开「设置」→ 填 API Key（默认 `https://api.deepseek.com/v1` / `deepseek-chat`，也支持其他 OpenAI 兼容服务）→ 回到「起局」填生辰与症候 → 自动跳转「推演」查看结果。

## 从源码构建

环境：JDK 17、Android SDK 36（含 build-tools 36）、Gradle Wrapper 9.1.0（已随仓库提供）。用 Android Studio 打开根目录亦可。

```bash
git clone https://github.com/oficcejo/dao-yi.git
cd dao-yi
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

产物：`app/build/outputs/apk/debug/app-debug.apk`。`local.properties` 由 Android Studio 自动生成或手动写入 `sdk.dir=/path/to/Android/sdk`（已加入 `.gitignore`）。

| 项 | 取值 |
|---|---|
| 语言 / UI | Kotlin + Jetpack Compose（Material 3） |
| 构建 | Gradle 9.1.0 / AGP 9.0.1 / compileSdk 36 / targetSdk 36 |
| 最低系统 | minSdk 23（Android 6.0） |
| 依赖 | 仅 AndroidX / Compose / Kotlin 协程 / JUnit；网络、JSON、加密均为零第三方实现 |
| 低版本兼容 | `com.android.tools:desugar_jdk_libs:2.1.5` 提供 `java.time` 脱糖 |

## 已知限制

- **未做真机 / 模拟器 UI 走查**：本机无 Android 设备与 AVD，Compose 布局仅做编译级与静态验证。
- 知识库与剂量表**未经中医师审校**；八字与五运六气**无现代循证依据**；汉代剂量折算存在不同学术标准。
- 大模型幻觉只能靠契约、闸门与降级缓解，**无法完全消除**；结果页固定展示「本次是否调用模型」与降级原因。
- Android 6 老设备若系统 CA 证书过旧，调用 HTTPS 接口仍可能握手失败（属系统信任库问题）；本地排盘不依赖网络。
- 本项目仅供本人自用研究，**不提供对外服务、不做疗效或诊断宣称、不计划上架应用商店**。
